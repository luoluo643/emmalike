# 轻酒馆保存插件（可选）

不装也能用。装上以后，轻酒馆保存聊天时只上传改动的那几条消息，不再每次上传整个聊天文件。长故事的聊天文件有好几 MB，手机上传慢或者网络不稳时，整份上传经常传不完。

不管装没装插件，保存时网络断了或者换了网络，轻酒馆都会先把这次改动存在这台设备上，网络恢复后（重开页面也算）自动补存，不会弹出「聊天无法保存」。如果这个故事在别处已经改过，就不会覆盖，只提示一声。

## 安装

需要服务器的管理权限。

1. 在酒馆的 `config.yaml` 里把 `enableServerPlugins` 改成 `true`。
2. 把本目录的 `index.mjs` 和 `chat-diff.mjs` 复制到酒馆的 `plugins/tavern-lite-save/`（`plugins` 和 `config.yaml` 在同一层目录）。Docker 部署时，`plugins` 一般挂载在宿主机的某个目录，复制到那里即可。
3. 重启酒馆。启动日志里出现 `Initializing plugin from …/plugins/tavern-lite-save/index.mjs` 就是装好了。

## 说明

- 只改当前登录账号自己的聊天文件。文件路径的规则和原版的保存接口相同。
- 每次只发改动的消息，同时带上整份文件的指纹。服务器上的文件跟指纹对不上（比如在别的设备改过）就拒绝写入，轻酒馆这时改用原版的整份保存。
- 写入走原版自己的保存函数，完整性检查和自动备份照旧。
- 需要酒馆 1.19 及以上（原版要导出 `trySaveChat`）。版本不够时插件会报告「不支持」，轻酒馆照旧整份保存。
