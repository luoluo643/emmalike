# 轻酒馆 Tavern Lite

SillyTavern 的轻量前端，以酒馆扩展的形式安装。界面可以用 CSS 自由美化，聊天请求仍由原版引擎处理。

## 为什么快

原版酒馆每次打开都要加载约 3MB、337 个文件。跨境网络下，冷启动约 25 秒；即使有缓存，二次打开也要 22 秒左右，因为每个文件都要回服务器确认一次。

以下是项目早期版本在模拟跨境 4G（延迟 200ms、5Mbps）下的历史测量，不代表当前构建的文件数量、体积或性能：

| 步骤 | 用时 |
|---|---|
| 打开登录页（无缓存） | 0.75 秒 |
| 登录到作品库 | 1.4 秒 |
| 打开对话、看到历史 | 2.2 秒 |
| 再次打开对话 | 1.9 秒 |

## 沿用原版生成流程

轻酒馆不自己拼提示词。原版酒馆会在后台的隐藏页面里加载，发送、重新生成都交给原版完成，聊天记录按原版格式保存。实际效果仍取决于模型、配置和插件；插件组合及其异步状态需要单独核验，不能保证所有扩展行为等价。

轻酒馆与原版之间只通过一个桥接层（`bridge.js`）通话：它运行在后台原版内部，调用原版自己导出的函数，而不是从外面模拟点击。原版改名或删掉某个函数时，只有对应功能会停用，并在“我的”页面底部列出来。

- 原版还在后台加载时，可以先阅读历史、输入文字。点发送后消息会排队，等原版就绪后自动发出；排队期间关闭或刷新页面，消息会放回输入框。
- 阅读页右上角 ⋯ 里的“打开原版界面”，会把已经在后台加载好的原版直接切到前台，用来做轻酒馆里没有的设置，不需要重新加载。
- 群聊显示在书架的“群聊”里，点开后在原版界面里打开。
- 原版弹出需要你确认的对话框（例如新账号的欢迎引导）时，不会打断你阅读：底部出现一条“原版界面需要你确认一下 · 去处理”。只有你正在等的操作（例如排队中的消息）被它挡住时，才会自动切过去，处理完再自动切回来。
- 原版的报错会同步显示在轻酒馆里。还没设置模型服务时，书架顶部和故事的输入框上方会提示，点一下进“开始使用”一步步设置。
- 较早的历史消息也经过原版的格式化流程（正则、Markdown），和最新消息显示一致。

### 原版消息周围的东西

- **思考过程**：推理模型的思考内容显示在回复上方，折叠成“思考了 N 秒”，点开看全文；模型思考时显示“正在思考… N 秒”。
- **对 AI 隐藏的消息**带“AI 看不到”标记；时间、楼层号、生成用时、token 数是否显示，跟随原版设置里的开关。
- **输入框上方的按钮**：快捷回复和酒馆助手的脚本按钮，原样出现在轻酒馆的输入框上方，点了由原版执行。
- **原版的 ✨ 扩展菜单**（生成图片、翻译、提示词查看器、变量管理器……）在输入框旁的“＋”（扩展功能）里。
- **消息上的其他按钮**（翻译、朗读、隐藏、存档点、跳到某个回复、其他扩展加的按钮）在消息菜单的“更多”里。
- **脚本放在页面上的东西**（例如角色卡脚本放的 Live2D 形象、扩展的悬浮按钮）浮在轻酒馆上面，可以点、可以拖；其余地方照常操作轻酒馆。

### 前端卡片和状态栏

- **酒馆助手的前端卡片**直接在轻酒馆里运行，按钮、变量、斜杠命令都作用在真实的聊天上，卡片弹出的提示显示成轻酒馆的通知。显示哪些消息里的卡片沿用酒馆助手自己的设置（例如“只渲染最近 3 条”）。轻酒馆显示卡片时，后台原版里的同一张卡会暂停，避免音乐、脚本跑两遍；打开原版界面时自动恢复。
- **其他扩展加在消息下面的面板**（例如 Horae 的状态栏）显示在消息下方的独立小窗里，样式与原版一致；在小窗里点击、输入，会转交给后台原版里真正的面板处理。面板如果打开了自己的窗口，底部会出现“原版界面里打开了一个窗口 · 去看看”。

## 怎么用

轻酒馆按阅读器的方式组织：书架上是你的**角色**，点进去就是**故事**正文。一个角色可以有多个故事（也就是原版的多个聊天），各自保存聊天记录；共享世界书、日记、变量或其他插件状态仍可能跨故事生效。

- **第一次用**：书架顶部的“还没设置模型服务”带你进“开始使用”：填你在故事里的名字（新账号），选一个模型服务（DeepSeek、硅基流动、Kimi、智谱、中转站；OpenRouter、Gemini、Claude、OpenAI 在“更多服务”里），填密钥（中转站还要地址），连接后会替你选好推荐的模型（模型多时可以搜索），可以让 AI 说一句试试。书架上只有原版自带的英文角色时，会顺便添加中文示例角色「林小满」，点“完成，开始聊天”就直接进入和她的第一个故事。以后在“我的 → 模型与预设 → 换一个模型服务”里可以重来。
- **书架**：最上面的“继续阅读”直接回到上次的故事。可以搜索，也可以点标签筛选；收藏的角色排在最前面。群聊在“群聊”里。
  - 每张卡右上角的 ⋯（或长按）：继续阅读、开始新故事、角色主页、收藏、导出角色卡、删除角色。
  - 右上角“＋ 添加”：导入角色卡（PNG、JSON 等，可以一次选多个），自己写一个新角色，或者添加中文示例角色「林小满」。
- **故事的名字**：没起名的故事按开始的先后叫“第 1 个故事”“第 2 个故事”……起了名就显示你起的名字。从某条消息“换个走向”出来的叫“第 1 个故事 · 走向 1”，存档点叫“第 1 个故事 · 存档点 1”。
- **角色主页**：封面（点开看原图）、简介、标签、全部故事（故事多时可以搜索名字和里面写过的内容）、世界书（点开就能看和改）、编辑角色。故事的 ⋯ 可以起名、删除（删除前会再确认一次）。
- **阅读**：往下读时顶栏会自动收起，往上滑或轻点正文就会回来。
  - 点顶栏的角色名：切换故事、开始新故事。
  - **Aa**：阅读设置——主题卡片（纸色、白色、护眼、羊皮、樱粉、夜间、墨蓝、跟随系统，以及你自己做的主题）、字号、字体、行距、段距、边距、首行缩进、中文两端对齐（英文段落总是左对齐，避免单词间空得很开）。改了马上生效，自动保存，换设备也一样。
  - **⋯**：这个故事（角色主页、开始新故事、分享这个故事）、设置（我的身份、模型）、打开原版界面。
- **换回复**：最后一条回复下方有 ‹ 换个回复 › 按钮，也可以在这条回复上左右滑动。滑到最后一个再往后，会生成一个新回复，原来的回复都留着。
- **继续写**：最后一条是角色的回复时，正文末尾有“继续写”。生成被停下或出错时，你的最后一句下面有“让 XX 回复”。
- **点消息右上角 ⋯（或长按消息）**：复制、编辑、换个走向（从这条另起一个故事）、删除（有多个回复时可以只删当前这个），以及“更多”：选择文字、从这条开始分享、在原版界面里编辑、原版的其他按钮。编辑和删除直接在轻酒馆里完成，效果和原版一样（正则、宏照常处理）。
- **故事里的线**：在故事里写「来个小剧场：……」「暂停剧情，生成一个番外……」，轻酒馆就从这句起记成一条线，写「回到正文」再回来；也可以长按消息 →「分线」自己划。每条线单独显示（「正文 › 小剧场 · …」），在哪条线里读就接着写在哪条线。以前写的可以在「⋯ → 故事里的线」里按发言找出换线的地方，或者让 AI 帮忙找（只发你每句发言的开头），看过、勾选后才分。装了 Horae 并开着它的故事线时，以 Horae 为准。注意：这只是分开显示，模型写的时候还是会看到整个故事；想让记忆真的分开，用「番外与平行线」拆成独立故事。
- **＋ 按钮**（输入框旁）：你装的扩展提供的功能（原版 ✨ 菜单里的那些）；没有时不显示。
- **编辑角色**（角色主页）：头像（点一下换一张图）、名字、人物设定、开场白、备选开场白，以及折叠起来的性格、场景、对话示例、简介和提示词。标签和深度提示词在编辑页里点“在原版界面里编辑”。
  - 改的内容随手自动存成草稿（存在这台设备上），关掉页面也不会丢，下次打开会问你要不要恢复。
  - 点“保存”才会改到角色；如果这段时间角色在别处（别的设备或原版界面）也被改过，会先告诉你，由你决定要不要覆盖。改了名字，以前的故事里也会换成新名字。
  - 保存后从服务器读回来核对一遍，并让后台的原版也换成新设定。改错了可以“找回上次保存前的内容”。
- **我的身份**（故事的 ⋯ 或“我的”最上面）：换身份、修改名字、头像和介绍（会告诉 AI），新建身份；有多个身份时，可以让一个故事固定用某个身份，或设一个默认身份。
- **我的**：我的身份、阅读设置、模型与预设（连接配置、模型、预设一键切换）、装到手机桌面、回复写好时提醒我；“外观”：做自己的主题、导入导出主题；“高级”：高级设置（世界书、预设与提示词在轻酒馆里改；格式、扩展、正则等在原版界面里）、省流量、自定义 CSS。
- **世界书**（“我的 → 高级设置 → 世界书”，或角色主页上的世界书）：全部世界书和它们给谁用；世界书多时可以搜索书名或角色名；每本可以搜索、按“常驻 / 靠关键词 / 已停用”筛选、在列表上直接开关一条、新建条目。关键词里夹着顿号或逗号的条目（原版会把“甲、乙”当成一整个词，要原样出现才触发）会提示出来：可以用“关键词带顿号”筛选，点开一条一键分开，也可以整本“全部分开”（会先确认，常驻条目不动）。点开一条，设置都用白话写着：
  - 标题（只给你看）、启用、什么时候尝试加入（常驻 / 故事里提到关键词时）、关键词（一行一个）、内容、放在哪里（角色设定前后、对话示例前后、作者注释前后、聊天记录里按深度，以及以谁的身份）、顺序。实际使用仍受关联、预算和其他条件影响。
  - “更多设置”里：还要满足的条件（次要关键词）、触发概率、分组（同组只留一条、组内权重、优先）、连带触发（不会被别的条目带出来 / 不会再带出别的条目 / 只能被别的条目带出来）、放不下时也要放进去、持续 / 冷却 / 推迟、往前看几条消息、区分大小写、只匹配整个词。
  - 保存前可查看实际字段差异、恢复单项，与原版的新修改逐项合并；保存后从服务器读回整本核对。保存期间继续输入仍作为本设备草稿保留。结果不明时只查验原操作；运行内容不一致时可明确选择“以服务器为准”。整本文件没有跨设备原子锁，仍需避免多人同时改同一本。关联、导入导出、改名等在“在原版界面里打开”操作。
- **预设**（“模型与预设 → 调整这个预设”或“高级设置 → 预设与提示词”）：搜索参数和提示词、查看具体差异、恢复单项。数字和开关直接应用；提示词文字先编辑，再点“应用到当前配置”，最后“保存到此预设”写入命名文件。也可“另存为新预设并使用”，等待原版完成切换。保存期间后输入的文字不会被成功提示清掉；未知结果只查验，不自动重发。草稿与恢复记录仅在本设备按账号保存。导入导出与提示词排序仍在原版界面里。

### 省流量

“我的 → 高级 → 省流量”按设备分别设置。打开后只看不写时不在后台准备原版（约 3MB），点输入框才开始；第一次发送会慢一些。关闭（默认）时打开轻酒馆就在后台准备，发送最快。

没准备好原版时照样可以看书架、读历史、切换故事；旧消息用简化排版显示。

## 安装

需要 SillyTavern 1.16.0 或更新版本。已在官方原版 1.16.0、1.17.0、1.18.0、1.19.0 上验证：酒馆里只装轻酒馆就能用，不需要别的扩展或服务器插件。

1. 打开酒馆，进入“扩展”面板，点“安装扩展”。
2. 粘贴本仓库地址。
3. **如果你是管理员，建议选“为所有用户安装”。** 这样轻酒馆的页面不登录也能打开，并显示自己的登录页。如果只为自己安装，需要先在原版里登录过一次，之后才能直接打开轻酒馆。
4. 安装后，在原版的扩展菜单（魔杖图标）里点“打开轻酒馆”，然后把打开的页面加入书签或添加到手机主屏幕。

轻酒馆的地址是：

```
https://你的酒馆地址/scripts/extensions/third-party/emmalike/app/
```

## 酒馆助手与更新

- **酒馆助手**：有些角色卡的界面、按钮和状态栏要靠[酒馆助手](https://github.com/N0VI028/JS-Slash-Runner)才能显示。在“我的 → 高级 → 酒馆助手”里可以一键安装，由你的酒馆直接从它的官方仓库下载。酒馆助手由 KAKAA 和贡献者开发，以 [PolyForm Noncommercial License 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0) 发布（只允许非商业使用）；轻酒馆不附带、也不修改它。
- **检查更新**：“我的 → 高级 → 检查更新”会向安装时的仓库查询有没有新版本，有的话一键更新，重新载入页面后生效；聊天记录和设置不受影响。轻酒馆每天最多自动查一次，有新版本时提示一次。
  - 为所有用户安装的轻酒馆，只有管理员能更新。
  - 不是从 GitHub 安装（例如直接复制文件）的轻酒馆，没法在页面里更新，要按原来的方式替换文件。

## 会访问哪些地址、保存什么

- **轻酒馆自己只会访问 GitHub**：一键安装酒馆助手时，你的酒馆从 `github.com` 下载它；检查更新时，浏览器从 `raw.githubusercontent.com` 读取本仓库的版本号。这两项都可以不用。
- 模型请求由原版酒馆按你的连接设置发出，也不经过任何第三方。轻酒馆只在你点「让 AI 帮忙找」并确认后，自己用你的连接问一次模型（只发你每句发言的开头）。
- 故事里的线记在聊天记录里：换线那一楼多一个 `tavern_lite_line` 字段，聊天信息里多一份 `tavern_lite_lines`；原版不认识它们，会原样保留。
- **不收集任何信息**，没有统计或上报代码。阅读设置和主题存在你的酒馆账号里；草稿、摘录、保存记录只存在这台设备的浏览器里，按账号分开。

## 可选：保存插件

[`server-chat-save/`](server-chat-save/README.md) 是可选的服务端插件，不装也能正常用。装上后，保存聊天时只上传改动的那几条消息，长故事在手机上不容易因为网络不稳传不完。它需要在酒馆的 `config.yaml` 里打开 `enableServerPlugins`，会以酒馆服务器的权限运行，只读写你自己账号下的聊天文件。安装方法见它的说明。

## 美化

主题系统：

- 阅读页的 **Aa** 里点主题卡片就能换，字号、字体、行距、段距、边距、首行缩进、两端对齐随手调。
- 点“自定义”卡片做自己的主题：背景色或背景图（可上传，也可从酒馆背景库选）、文字和强调色、对白和旁白颜色、卡片不透明度、背景模糊、毛玻璃、圆角、字体，再加首字下沉、纸张纹理等一点即开的效果。整页就是预览。
- 每个主题可以带自己的 CSS，懂一点 CSS 就能做出完全不同的样子；“我的”里还有对所有主题生效的自定义 CSS。
- 主题可以单独分享成文件，背景图一起打包；朋友导入后就是他自己的一份。

全部同步到账号。可用的变量、类名和示例见 [THEMING.md](THEMING.md)。

## 已知限制

- 第一次打开（无缓存）时，原版要在后台加载，第一条消息要等原版就绪才会发出。模拟跨境 4G 下约 30 秒；之后在同一页面里发送不用再等。
- **长对话在一台设备上第一次发送会慢。** 原版拼提示词时，会为每条历史消息单独向服务器请求一次 token 计数，一条接一条地等。170 条消息在 200ms 延迟下约 40 秒。计数结果会缓存在浏览器里，所以同一台设备上每个对话只慢这一次。轻酒馆会在对话打开后于后台预先跑一遍（与原版提示词管理器相同的试运行），你先阅读一会儿再发送，就能省掉大部分等待。
- 前端卡片和状态栏需要后台原版就绪后才出现；生成过程中的流式卡片在生成完成后显示。其他嵌入内容（非酒馆助手的 iframe）仍显示为占位文字。
- 群聊需要在原版界面里使用。
- 角色的名字、头像、标签和深度提示词还要在原版界面里改（编辑页底部有直达入口）。
- 原版酒馆 1.19.0 有一个问题：网址里带任何查询参数（`?xxx`）时，发送按钮会失效。轻酒馆加载原版时已经避开了这个问题。
- 已验证的酒馆版本：1.16.0、1.17.0、1.18.0、1.19.0。更新的版本可以使用，但会提示“未在此版本验证”。

源码在 `src/`，构建产物输出到 `app/`。`app/` 需要和源码一起提交，因为朋友安装时不会执行构建；CI 会检查两者是否一致。桥接层 `bridge.js` 不经过构建，由轻酒馆在运行时注入原版页面。测试说明见 [tests/README.md](tests/README.md)。
