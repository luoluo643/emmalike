# 分享与字体的异步操作

- 分享开始时立即锁定当前任务。关闭按钮、遮罩、Esc、系统返回、页面离开都会取消尚未交付的导出。已交给浏览器或系统的分享不做撤回；旧任务不再提示或关闭新面板。
- 字体加载与 FontFaceSet.ready 共用 15 秒期限。超时或加载失败后，长图使用系统字体，完成提示说明这一点。
- 添加字体的读取结果只属于发起它的面板。关闭面板或改选其他字体会取消旧任务。网址按来源和 family 复用；文件在 Web Crypto 可用时按 SHA-256 复用。保存时再次检查重复与 20 个名额，避免并发完成时超限。
- 删除字体立即影响账号字体库，与主题草稿保存分开；确认区说明其他主题也会受影响。
- 选段保留消息内的 q/em/i/strong/b 语义；长图姓名遮蔽在完整文本上匹配后再保留周围样式，跨样式姓名也必须隐藏。

上述交互不新增动画，沿用现有面板、按钮、焦点和返回行为。

## 验证

`npm run test:unit` 包含字体容量、来源查重、跨样式姓名遮蔽、字体等待超时及取消测试。

`npm run test:share-fonts` 在 Chromium 中运行真实阅读设置、分享面板、历史返回和 Canvas 渲染；仅引擎与远程字体响应使用测试替身，无需连接酒馆账号。支持 CHROME_PATH、PLAYWRIGHT_CORE。

隔离酒馆的 `tests/e2e-fonts.mjs` 另验证重复文件不再上传、网址复用、账号同步和删除；`tests/e2e-share.mjs` 验证实际分享下载。使用 `tests/run-isolated.sh` 的独立实例运行，不能使用生产账号。

## 纵向菜单合并回归

阅读设置打开时只允许主题条自身横向定位，不滚动整个面板；手机网格下保持标题、关闭按钮和字号可见。分享设置的 fieldset 保持单列 grid，内部选项保留 16px 留白，导出按钮铺满整行。保留空内容禁用、有效条数统计和生成期间锁定。

组件回归同时验证靠后的内置主题、20 个自定义主题、桌面横向定位、只含图片或空白的楼层，以及字号滑块在 touchMove 中连续变化。

书架顶部保留主题按钮至少 44px 的点击区域；480px 及以下采用两行。回归覆盖 320/390/421/430/480/481/600/1440 宽度、17/26 字号以及头像，检查标题文字与按钮互不重叠。
